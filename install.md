# Browserless MCP — agent installation guide

Read the one canonical, immutable
[Browserless setup skill](https://www.browserless.io/agent-setup/v1.0.0/SKILL.md).
It owns product routing, project inspection, approval, authentication safety,
real-browser verification, cleanup, and rollback.

When that skill selects Browserless MCP, use the MCP-owned machine export at
[`setup/browserless-mcp-setup.json`](setup/browserless-mcp-setup.json) for the
current hosted endpoint, runtime requirements, client syntax, authentication
order, full/compliant surface inventories, and verification call. This file is
only a compatibility pointer; it intentionally does not duplicate those
instructions.
